# Beauty Atelier — sajt

Statični sajt salona Beauty Atelier (Prve pruge 1b, Zemun). Sve je u jednom fajlu `index.html` (slike, fontovi, mapa, uslovi i politika privatnosti su ugrađeni) — nema drugih fajlova za postavljanje.

## Hostovanje na GitHub Pages

1. Napravi novi repozitorijum na GitHub-u.
2. Dodaj oba fajla iz ovog foldera u koren repozitorijuma: `index.html` i `.nojekyll`.
3. Otvori **Settings → Pages**.
4. Pod **Source** izaberi **Deploy from a branch**, granu `main` i folder `/ (root)`, pa sačuvaj.
5. Za minut-dva sajt je dostupan na:
   `https://TVOJ-KORISNIK.github.io/IME-REPOA/`

## Sopstveni domen (opciono)

U **Settings → Pages → Custom domain** upiši svoj domen (npr. `beautyatelier.rs`) i podesi DNS kod registrara prema uputstvu koje GitHub prikaže.

## Izmene

Za izmene teksta ili cena javi se — dobićeš novi `index.html` koji samo zameniš u repozitorijumu.
